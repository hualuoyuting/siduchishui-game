# 四渡赤水

**2D 俯视角像素风战略沙盘推演游戏** — 还原1935年红军长征四渡赤水的真实历史，你扮演全军指挥，在川黔滇边界的真实地形上决定每一步进攻方向和战术。

## 史实依据

本游戏严格依据真实历史设计：
- 赤水河走向、渡口位置、地形均按真实地理还原
- 四次渡河的时间、方向、战果均参照党史资料
- 敌我兵力：红军约3.7万人，国民党军约40万人

## 四次渡河

| 次数 | 时间 | 渡口 | 方向 | 战略意图 |
|------|------|------|------|----------|
| 一渡 | 1935.1.29 | 元厚、土城 | 向西入川南 | 土城战斗失利后主动撤出 |
| 二渡 | 1935.2.18-21 | 太平渡、二郎滩、九溪口 | 向东回黔北 | 回师娄山关、再占遵义 |
| 三渡 | 1935.3.16-17 | 茅台镇 | 向西再入川南 | 佯动北渡长江，诱敌向西 |
| 四渡 | 1935.3.21-22 | 太平渡、二郎滩、淋滩 | 向东再回贵州 | 金蝉脱壳，南渡乌江逼贵阳 |

## 核心玩法

```
大地图选目标 → 战前选战术 → 自动战斗结算 → 行军补给 → 下一个目标
```

- **你是全军指挥**：在真实地形的川黔滇地图上，选择下一个进攻目标
- **战前决策**：正面强攻 / 侧翼迂回 / 夜间偷袭 / 伏击打援，分配兵力
- **自动战斗**：系统根据战术、兵力、地形自动演算战报
- **章节约束**：四章对应四次渡河，大方向按史实推进，但战术由你定
