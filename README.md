# 四渡赤水

**2D 俯视角像素风战略沙盘推演游戏** — 你扮演红军全军指挥，在1935年川黔滇边界决定每一步进攻方向和战术，亲眼见证四渡赤水这一军事奇迹。

## 核心玩法

```
大地图选目标 → 战前选战术 → 自动战斗结算 → 行军补给 → 下一个目标
     ↑                                                    ↓
     ←──────────── 章节推进 / 剧情事件 ←──────────────────
```

### 你是全军指挥
- 在赤水河两岸的川黔滇地图上，选择下一个进攻目标
- 打哪里由你定：娄山关？遵义？茅台镇？扎西？

### 战前决策
- 选了目标后，决定怎么打：正面强攻 / 侧翼迂回 / 夜间偷袭 / 伏击打援
- 分配兵力：主攻多少、佯动多少、预备队多少
- 不同战术组合，完全不同的战斗结果

### 自动战斗
- 不用你操作，系统根据你的战术、兵力、地形自动演算
- 显示战报：我方伤亡、敌方伤亡、缴获、胜负
- 打输了会怎样？可能要撤退、可能丢地盘、可能影响后续

### 四章对应四次渡河
| 章节 | 渡河 | 战略目标 |
|------|------|----------|
| 第一章 | 一渡赤水 | 土城失利后西进扎西 |
| 第二章 | 二渡赤水 | 回师黔北，再占遵义 |
| 第三章 | 三渡赤水 | 声东击西，佯攻长江 |
| 第四章 | 四渡赤水 | 金蝉脱壳，巧渡金沙江 |

## 操作

| 按键 | 功能 |
|------|------|
| 鼠标点击 | 选择地图据点 / 选项 |
| 空格 | 继续 / 下一步 |
| Esc | 返回 |
