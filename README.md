# 四渡赤水 (Four Crossings of Chishui)

一款基于 **Unity 引擎**的第一人称射击游戏，还原1935年中国工农红军长征途中四渡赤水的经典战役。

## 游戏简介

1935年1月，遵义会议后，红军面临国民党四十万大军的围追堵截。在毛泽东同志的军事指挥下，红军三万余人在川黔滇边界的赤水河两岸，声东击西、忽南忽北，四次渡过赤水河，巧妙摆脱了敌人的围追堵截，取得了战略转移中具有决定意义的胜利。

玩家将扮演一名红军战士，亲历这一经典运动战战役。

## 章节内容

| 章节 | 名称 | 历史事件 | 核心玩法 |
|------|------|----------|----------|
| 第一章 | 土城突围 | 一渡赤水 (1935.1.29) | 阵地防守 + 渡河突围 |
| 第二章 | 娄山关战斗 | 二渡赤水 (1935.2.24-28) | 城市巷战 + 关口攻坚 |
| 第三章 | 茅台镇渡河 | 三渡赤水 (1935.3.16-17) | 声东击西 + 渡河作战 |
| 第四章 | 巧渡金沙江 | 四渡赤水 (1935.3.22-4.初) | 急行军 + 金蝉脱壳 |

## 技术栈

- **引擎**: Unity 2022.3 LTS (推荐)
- **语言**: C#
- **渲染**: URP (通用渲染管线)
- **目标平台**: PC (Windows)

## 项目结构

```
├── Assets/
│   ├── Scripts/
│   │   ├── Player/          # 玩家控制器、生命、体力
│   │   ├── Weapons/         # 武器系统、弹道
│   │   ├── Enemies/         # 敌人AI、敌人生命
│   │   ├── Mission/         # 任务系统、目标点
│   │   ├── Raft/            # 竹筏渡河系统
│   │   ├── UI/              # HUD、任务面板
│   │   ├── Chapter/         # 章节管理
│   │   └── Audio/           # 音频管理
│   ├── Scenes/              # 游戏场景
│   ├── Prefabs/             # 预制体
│   ├── Art/                # 美术资源
│   └── Audio/              # 音频资源
├── ProjectSettings/         # 项目设置
└── README.md
```

## 快速开始

1. 安装 Unity Hub 并添加 **Unity 2022.3 LTS**
2. Clone 本仓库
3. 用 Unity Hub 打开项目
4. 打开 `Assets/Scenes/Boot.unity` 开始运行

## 操作说明

| 按键 | 功能 |
|------|------|
| W A S D | 移动 |
| 鼠标 | 视角/瞄准 |
| 鼠标左键 | 射击 |
| Shift | 奔跑 (消耗体力) |
| 空格 | 跳跃 |
| E | 交互 (登船/使用) |
| R | 换弹 |
| F | 火力模式切换 |
| Tab | 任务日志 |
